# THE JARGON LEDGER — programme-internal language in the corpus PROSE, for the deferred language pass
*Opened r1310 (Daryl-directed). A running list, built as the idiom avenue (avenue 9c) runs on each paper,
of **programme-internal tracking jargon that has leaked into the paper prose** and should later be translated
to **standard physics vocabulary**. This is the accumulation target for the deferred **do-not-assert LANGUAGE
pass** (the arsenal's "clean tracking jargon from prose, ~9 papers"): when we run that pass, we comb the corpus
for these terms and replace each at the right weight. Built now, executed later.*

## THE DISTINCTION (the filter — do NOT over-list)
- **EARNED IDIOM — stays.** A coined physics concept the corpus *defines and uses consistently* is not jargon;
  it is vocabulary. Leave it. E.g.: *the slicing curve / operator*, *the construction gauge*, *the bend of the
  cut*, *the throat*, *the bead*, *the lap*, *the seam*, *the leaf / stacking / vantage*, *R-odd / R-parity*,
  *the null rulings*. These are the paper's own terms of art, standard-quality once introduced.
- **TRACKING JARGON — translate.** Internal *process / status / bookkeeping* language that belongs to how we
  *work* the corpus, not to the physics, and that has leaked into the prose. This is what this ledger lists.

## THE LIST (term · what it means · standard replacement (context-dependent) · sites)
Format per entry — the replacement is a *menu by context*, chosen at translation time, not a blind 1:1.

- **`do-not-assert` / `held do-not-assert`** — the flagship. Programme status meaning "grounded/built as
  structure, but this further step is not claimed." → **standard menu:** *"we conjecture"* / *"conjecturally"*
  (when it is a genuine conjecture) · *"remains to be established empirically"* / *"the world-correspondence is
  left to the data"* (when it is an empirical-correspondence gap) · *"an open question"* (when it is a genuine
  frontier) · *simply drop and assert* (when the thing is in fact built — the r1299 defect). Choose by which
  the completion-shield verdict says it is. **Sites:** pervasive — P3, P13, P14 especially; scan corpus-wide at
  pass time.

*(entries accumulate as the idiom check runs each paper; see the SPOT-CHECK LOG in THE_ARSENAL for which papers
have been combed for jargon so far)*

- **`(Grounded: …)` / `(Confirmed: …)` — status-annotation wrappers.** A parenthetical prefixing a physics
  statement with its programme verdict ("(Grounded: the parity measures chirality, the exchange reading
  excluded…)"). → **standard:** drop the wrapper, state the physics directly (the grounding is shown by the
  argument, not announced). **Sites:** P12 §240 (`algebroid_paper`); scan corpus-wide.

## CANDIDATES flagged for review (not yet confirmed jargon — decide at pass time)
- **`walled` / `is walled`** (verb, e.g. "su(3) is walled") — borderline. *The wall* (P9's radiative boundary)
  is earned idiom and stays; *walled* as a verb for exclusion may read better as *"excluded (as a substrate
  isometry)"* / *"obstructed."* Review in context; do not auto-replace. **Sites so far:** P12 §240 ("its
  continuous parent walled by su(3)⊄so(5,1)").

- **`forced within CR`** (weight-term, pervasive in P14 — 4×, and across the corpus) — the programme's careful
  coherence-marker: "established given CR's maximal-symmetry principle, world-correspondence held open." EARNED
  as a precise weight-flag (not loose), but reads as programme-internal. → **language-pass options:** keep (it
  is a genuine, defined weight-term) · or expand on first use to *"forced given CR's maximal-symmetry criterion
  of necessity (coherence, not yet correspondence)"* then use the short form. Decide at pass time; do NOT flatten
  the weight it carries. **Sites:** P14 (§195/§208/§222/§224), corpus-wide.
