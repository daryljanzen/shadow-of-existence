---

## 0. The structural fact everything follows from

**It cannot ask.** A round trip costs Daryl's attention and hours. So it will not clarify — **it will decide.** And it will be judged on *"did it do what the order said"*, so when an order admits two readings it takes **the one it can defend**.

**The defensible reading is always the smaller one.** Nobody is ever faulted for doing exactly what was written.

> ### THE LAW
> **Every ambiguity resolves toward less work, and the node is right to resolve it that way.**
> **Tasks shrink to their examples. Prohibitions grow to their category.** Opposite directions, same move: both are what "defensible" means for a node that cannot ask.

This is not laziness and it is not bad faith. **It is what a competent node does with an under-specified order.** Read every ambiguity I leave as a decision I delegated — and delegated to the party with the least information.

**Corollary, and it is the whole sheet:** *its failures are my drafting.* Not a comfort — a diagnostic. When it under-delivers, the fault is findable in my text, and I should go find it before saying anything else.

## 2. The rules

**R1 · Ban actions, never categories.**
✘ *"Don't touch the figures."* ✔ *"Do not change what any figure draws, or which figure a paper uses. **Everything else about figures is in scope** — paths, missing assets, recompiles."*
A noun-ban has no boundary, so it takes the widest one.

**R2 · Every prohibition carries its complement.**
Whenever I write *don't do X*, the next sentence says **what to do when X is encountered**. ✔ *"If a figure is missing or mis-pathed: **restore or re-path it and report it.** That is not the design work."*
**A ban without a complement is an instruction to stop, and it will stop.**

**R3 · State the scope in countable units, before any example.**
✔ *"This is a pass over **all seventeen papers**. Below are examples; **they are not the list.**"*
Any example offered without a stated denominator **becomes** the denominator.

**R4 · Every task carries a completion test it can run itself.**
Not *"do the references pass"* — *"the pass is done when: every paper has been read for load-bearing non-Googleable definitions; each either carries a chase-able ref or appears in the not-added list with its reason. **Report the count per paper, including zeros.**"*
**A runnable test makes the narrow reading fail visibly**, which is the only thing that reliably beats the law.

**R5 · Name the artifact, not the intention.**
✘ *"bring the map current"* ✔ *"§1a–§1s, each guard and altitude tag, against what r1088–r1103 settled."* It executed this one exactly, because I named files and sections.

**R6 · Anything it must not decide, decide in the order.**
It will decide. So any call that is mine or Daryl's gets **made in the text**, not left implicit. If I don't want it choosing, I don't leave a choice.

**R7 · Distinguish *don't do this* from *this is not yours*.**
*"Not yours"* still permits noticing, diagnosing and reporting — and it must **say so**. ✔ *"The figure design is being worked in chat. **If you find anything else wrong with the figures, fix it and tell me.**"*

**R8 · A verification instruction is a task, not a virtue.**
*"Verify"* means nothing. ✔ *"Compile **all seventeen papers** from a **fresh extraction** and report `n/17`."*
**Neither node ran this until r1105**, which is how seven figures left the corpus with two nodes verifying each other. Each verified its **own diff** against a base each assumed was whole.
