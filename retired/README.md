# retired/ — documents that have been filtered and are no longer planned from

A document lands here only after it has been **read end to end** and its live content placed into
`../CONSOLIDATE_THE_PLAN_AND_INDEX_THE_PROGRAMME.md`. Each file keeps a banner at its top saying where its content went.

**These are records, not plans.** Nothing here is to be worked from, and nothing here earns a place in the
programme by having existed. If something in one of these files is not reachable from `CONSOLIDATE_THE_PLAN_AND_INDEX_THE_PROGRAMME.md`,
that is a **filtering miss** — raise it in the plan rather than reviving the file.

They are kept rather than deleted because the record must be walkable in both directions: a future reader
should be able to see what was tried, what it became, and why.

**Its pair is `../THE_WISDOM_LEDGER.md`.** This folder archives whole **documents** with their arc placement;
the wisdom ledger archives the **scraps** — the fragments of hard-won knowledge dropped inside living documents,
which have the same lifecycle and, until r1641, had no equivalent record. *Both keep the record walkable in both
directions, at the two scales work actually happens at.*

Other documents still reference these by name; those references resolve to `retired/<name>` from r1452.
