## THE PREDICATE, FIXED HERE BEFORE IT IS RUN

The row's own usage is a RUNNING COUNTER — *"no new member, the count holds at `91`"*,
*"a seventh blindness member"*, *"member `88` stands"*.  So:

 ** A BLINDNESS-MEMBER COUNT IS A NUMBER THE ROW STATES AS THE RUNNING TOTAL OF THAT
 SERIES, AND THE AGGREGATE IS THE LATEST SUCH STATEMENT — NOT THE NUMBER OF
 ANNOUNCEMENTS AND NOT THE LARGEST NUMBER IN THE ROW. **

A statement qualifies only if the number stands in one of the forms the row actually
uses: *holds at N*, *HELD at N*, *N blindness members*, *member N*, *the Nth member*,
*no new member … N*.  The instrument prints every site it matched with its surrounding
words, so the predicate is checkable against the row by a reader rather than trusted.

⌗ **Numbers that are NOT counts of this series and must be excluded by construction:**
a revision id (`rNNNN`), a row id (`PO-NN` — and `PO-91` exists, which is the trap), a
receipt or ledger id, and any number inside a block the row marks superseded.
