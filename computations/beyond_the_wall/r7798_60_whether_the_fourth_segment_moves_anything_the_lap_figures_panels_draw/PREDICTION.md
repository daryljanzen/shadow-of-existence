## The guard this registration is built on, named first

**Which object is each panel drawing?** `r7797`'s own order already answers it for the caption's
*"three closed-form segments"* — that is about the vacuum lap and stays. But a panel is not one object:
its **curves** may be the vacuum cut's while a **clause of its caption** speaks about the actual
history. ⇒ *a sentence located in the paper is a fact about the object the paper is talking about, and
which object that is has to be established first.* **So Ⓐ establishes the object before Ⓒ and Ⓓ say
anything about movement.** An answer of the form "the panel changes" or "the panel does not change",
given without that split, would be answering about an object the question never fixed.

⌗ *And the second guard applies to the verdict: `r7138`'s. If the difference between what the panel
draws and what the bent cut would have it draw does not survive being drawn — if it is smaller than
the figure can carry — then it is not a difference in the panel, however real it is in the geometry.
**That is a measurement, not an opinion, and Ⓒ⑨ registers it as one.***
