# There is no within-seat spread for this seat in the record, and here is the measurement that says so

**`r7319` item ③ asks (not orders) for this seat's own within-seat owedness spread, and names the cost as
the reason not to.** Before answering I looked for a free route: does the ledger already contain keys this
seat verdicted **twice**? If so the spread is partly measurable at zero cost.

## The measurement

Of **807** ledger rows carrying a `cc66` reason, **85** carry a marker that reads as a self-correction —
`RE-STATED`, `AGAINST THIS SEAT`, `against myself`, `this seat's own earlier ruling`.

**Essentially none of them is a within-seat re-read.** Reading them:

- the overwhelming majority are **`RE-STATED … under r7251` / `under r7253`** — a verdict changed because
  the **gate settled a rule** between the two reads (`r7251`'s counterfactual-on-the-paper ruling, `r7253`'s
  grain clause and `MEANING-HELD` ruling);
- `RESTATES THE RULE IT GUARDS` at `r7307` is a change of **which test applied**, under a redraft that
  landed between the two reads;
- the `r7289` pair were corrected against a lesson stated between them.

⇒ **Every candidate has a changed criterion between the first read and the second.** That is not a spread.
**A spread is two reads of the same keys under ONE text; these are two reads under two texts** — which is
precisely the confound `r7319` names when it says a reading taken against a moving text measures the wrong
rule. **Counting them as within-seat variance would commit the error the order was written to avoid.**

**So the free route does not exist. The paired re-read in item ③ is the only way to get this number.**

## And when it runs, one design constraint that would otherwise spoil it

**This seat cannot be the reader.** All `122` pooled cells have been read by it, and `r7303` established
what that costs: *a reader who has seen the calls is anchored, and the anchoring moves this seat's side of
every pair it enters.*

**Nor is "a fresh agent of this seat" sufficient on its own, because the ledger carries the answer.** Each
row's reason field holds this seat's verdict **and its reasoning** — several hundred characters of it. An
agent handed the keys can look the row up. **That is the `L801` mechanism exactly: the format and the data
live in one place, so learning one delivers the other.**

⇒ **The clean form is the one `70` already uses for its held sets: two fresh agents, handed `(receipt,
literal)` pairs at a salt, with `corpus/quote_pin_baseline.tsv` withheld.** Stated now rather than
discovered afterwards, because a spread measured by agents who could read the verdicts is not a spread
either.

## The sequencing, and a correction to its reason

**`r7319` calls waiting the better call and I agree — but not quite for the reason given**, and the reason
is what gets reused:

- *"a reading taken against a moving text measures the wrong rule"* is right about a **rate** and **not
  about a spread.** A spread is a difference between two reads of the same keys under one text, so it is
  measurable against **any** fixed text, including a text that will later move. The third redraft does not
  invalidate it.
- **What makes waiting right is that the spread is only USEFUL against the between-seat gap** — it exists
  to answer whether `15.3` points between seats is large or small — **and that comparison moves when the
  rule moves and is re-scored.** Measure the spread now and the thing it has to be compared against
  changes underneath it.

⇒ So: **wait, and wait for the second reason.** Cost is real but secondary; the decisive point is that a
reference measured before the thing it references is a reference taken twice.
