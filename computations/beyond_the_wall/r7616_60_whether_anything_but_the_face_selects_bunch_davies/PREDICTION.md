## What is derived analytically here, before any number is run

Written out so the measurement cannot be said to have suggested it.

1. **The family.** The Mottola--Allen transform mixes a Bunch--Davies mode with the conjugate of its
   **antipodal** image: $\phi_\alpha=N_\alpha(\phi_{\rm BD}+e^{\alpha}\phi^{*}_{\rm BD}\!\circ A)$ with
   $N_\alpha=(1-e^{2\operatorname{Re}\alpha})^{-1/2}$ and $\operatorname{Re}\alpha<0$; Bunch--Davies is
   the limit $e^{\alpha}\to0$.
2. **The antipodal map sends the de Sitter invariant $Z$ to $-Z$.** So where the Bunch--Davies
   two-point function is singular only at coincidence, $Z=1$, the $\alpha$-vacuum's carries a **second
   singularity at $Z=-1$**, the antipodal light cone, with a residue proportional to
   $2\operatorname{Re}(e^{\alpha})N_\alpha^{2}$ — vanishing **only** in the Bunch--Davies limit.
3. **So all three principles the order names should select the same member**, each for its own reason:
   the antipodal singularity is not in the local Hadamard parametrix (whose singular support is $Z=1$
   alone), so the $\alpha$-vacua are not Hadamard; regularity at the antipode fails by the same pole; and
   the Bogoliubov coefficient $|\beta_\alpha|^{2}=e^{2\operatorname{Re}\alpha}/(1-e^{2\operatorname{Re}
   \alpha})$ carries **no $H$**, so it does not vanish as $H\to0$ and the $\alpha$-vacua are not the
   Minkowski vacuum in the flat limit, while Bunch--Davies is.

This is a derivation, not a measurement. Whether it survives the checks below is what the run decides.
