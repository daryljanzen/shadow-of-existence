## THE UNIT: A COMMENT BLOCK, NOT A COMMENT LINE

A `%` comment **block** is a maximal run of consecutive lines whose first non-space character is `%`.
Its text is those lines with the leading `%` and one following space removed, joined. ⌗ *A block is the
unit because that is how the corpus writes them — `P16`'s `STATUS` note is nine lines of one claim, and
keying per line would split one sentence into fragments and manufacture keys.*

⌗ **The `source` of every baseline row will be recorded (`PROSE` / `COMMENT`)**, so the before/after
difference is readable off the file rather than taken on trust.
