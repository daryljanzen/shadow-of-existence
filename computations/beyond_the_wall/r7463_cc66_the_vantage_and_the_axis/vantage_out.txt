==============================================================================
  STEP 4 -- (a) IS CHART H ADMISSIBLE?  the sweep-axis criterion
==============================================================================
  A sweep is a reduction by an SO(3) isometry whose orbits are the swept
  2-spheres.  Its axis is the FIXED-POINT SET of that action, so the orbit
  through a point of the axis must be a point: A = 0 there.  That is the
  criterion, and it is a statement about an area, hence an observable.
    axis at z = 0 :  A = 16*pi*M**2   => admissible as a sweep axis: False
    axis at z = pi:  A = 0            => admissible as a sweep axis: True

  ⚠ AND A SUBTLETY THAT CUTS AGAINST THE EASY VERSION OF THIS ARGUMENT.
     In the maximal Schwarzschild MANIFOLD the SO(3) action has no fixed
     point at all: A = 4 pi r^2 vanishes only at r = 0, and r = 0 is not a
     point of that manifold.  So the sweep axis is a BOUNDARY locus the
     orbits shrink toward, not a fixed point sitting inside the spacetime.
     The criterion below is therefore 'the locus the orbit area degenerates
     at', which is where P2's SPATIAL sweep does have an axis, and it is
     still unique:
       A(rho) = 4 pi rho^2 vanishes only at  {0: 2}  (value: multiplicity)
       and on the chart's own domain rho > 0 the solution set is [] -- EMPTY, which is the subtlety
       restated as arithmetic: the one candidate axis is not in the
       manifold the orbits live in.

    chart N sweeps about z = pi  -> ADMISSIBLE
    chart H sweeps about z = 0   -> INADMISSIBLE: the orbit there has
      area 16 pi M^2, so z = 0 is not fixed by any SO(3) action whose
      orbits are these 2-spheres.  The vantage is NOT free to choose it.
