## What is derived analytically here, before any number is run

Written out so the measurement cannot be said to have suggested it. From `P15` eq:proper-frame,
$ds^2=-d\tau^2+(\partial_\chi r)^2d\chi^2+r^2d\Omega^2$ with $r=r(\tilde\tau)$, $\tilde\tau=\tau+\chi$:

1. A radial null ray satisfies $d\tau=\pm(\partial_\chi r)\,d\chi$, so along it
   $d\tilde\tau=(1\pm\partial_\chi r)\,d\chi$.
2. The proper length a photon traverses, read in the local fundamental observer's own frame, is
   $\sqrt{g_{\chi\chi}}\,d\chi=(\partial_\chi r)d\chi$, which the null condition makes **equal to
   $d\tau$** — the observer's proper time, not the layer time $\tilde\tau$.
3. Therefore the light-travel comoving accumulation is $dD=r_0\,d\tau/r$, while the integral the
   implementation carries, $\int c\,dz/H$, is $r_0\int d\tilde\tau/r$ — because $H=c(\partial_\chi
   r)/r$ is the $\tilde\tau$-rate.
4. On the ray the two times are related by $d\tau=\dfrac{\partial_\chi r}{1+\partial_\chi r}\,
   d\tilde\tau$. **So the two candidate "light-travel distances" differ by exactly the non-synchrony
   factor $\partial_\chi r/(1+\partial_\chi r)$, epoch by epoch, and that factor is strictly below 1.**

This is a derivation, not a measurement. Whether it survives the checks below, and what it is worth
numerically, is what the run decides.
