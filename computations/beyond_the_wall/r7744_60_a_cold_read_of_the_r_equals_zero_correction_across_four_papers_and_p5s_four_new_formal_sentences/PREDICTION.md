The horizon cubic is `r³ − r + 2M`. Its value **at `r = 0` is `2M`**. So

```
r = 0 is a root  ⟺  2M = 0
```

exactly, with no interval and no approximation. **That is the whole predicate for the sweep**, and
it is derivable rather than guessed — which matters, because `r7740 ⑥` and `r7742`'s own `Ⓐ⑥` were

the massless member.*

**Both components meet `r = 0` exactly on the massless members.** `r7742`'s correction entry
printed that and I did not read it as the point; this revision starts from it.
