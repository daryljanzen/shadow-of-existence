Its condition was `not _hit`, where `_hit` is the claim-sites last written by an order commit whose
subject carries an EVEN revision id.

1. **The selector matched nothing.** It required a subject to *begin* `orders r####`. The gating seat

**19 commits in the last 400 carry an EVEN revision id and a seat stamp that is not this line's** —
all of them seat `70`, working under this line's order ids. **That is the class parity cannot see.**
None of this line's own commits is caught, so the repaired selector does not invert the gate's
meaning; the report is of *who* and not only of *how many*. The old gate's text said **six**; the
measured count is **19**, so its literal was stale as well as unmeasured, and the count is now
**printed by the run** rather than written in.
