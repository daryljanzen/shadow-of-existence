turned into a gate, with three clauses:

  ⓐ ** the gate asserts that each series' value as stated in the row's LIVE STANDING

     standing state is the copy. **
  ⓑ ⚠ ** it must be keyed on the LIVE BLOCK, not on the file **, or it reads one of the
     twenty-nine superseded values and disagrees with a correct row.  The live/superseded
     boundary is the `⛭ THE LIVE CLAUSE (SET rNNNN)` marker.

     characters. **

⌗ And it is this seat's to build because *"reimplementing your predicate is the defect
this row names"* — so the gate calls the derivation already registered at `r7456`

## THE CONTROLS, AND WHAT VOIDS THE RUN

 Ⓥ①  THE SUPERSEDED-LEAK CONTROL.  Run the gate against a row whose live block is
     ARTIFICIALLY moved back to a superseded clause, and it must report the mismatch
     rather than the agreement.  ** If it passes on a deliberately stale live block, it
     is reading the file and not the block, and THE RUN IS VOID. **

 Ⓥ②  THE POSITIVE CONTROL.  Mutate the live block's stated member value by one and the
     gate must go red.  ** If it stays green on a mutated copy, it asserts nothing, and
     THE RUN IS VOID. **

 Ⓥ③  THE REACH CONTROL, which is the one `r7456` failed.  The widened reader must return
     both a LIVE row and a STRUCK row by name — `PO-78` and `PO-75` — and the struck
     one is the row `r7456` could not see.  ** If `PO-75` is still invisible, the
     widening did not happen and THE RUN IS VOID. **

 ⌗ A control that fires is reported and the run is kept, as `r7450`'s and `r7454`'s
